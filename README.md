# Guess The Number
I decided to make a command-line game where you guess a number in Java.
I was bored so I made a fun little game to hone my Java skills.
You can run the JAR file from the releases if you don't feel like building the project yourself.

## Instructions on running the jar file
Navigate to the directory that you downloaded the jar release with
```bash
cd DOWNLOAD_DIRECTORY_PATH # replace this with your actual path
java -jar GuessTheNumber.jar
```
Suggestions appreciated!
